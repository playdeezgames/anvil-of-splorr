Anvil of SPLORR

Back to the tools

A suite of small editors for making the art and worlds of games: palettes, 4-bit pictures up to 64x64, tilesets, worlds (terrain, sprites, maps, characters, features, items, triggers, sounds and a play mode to walk around), glyphs and fonts, plus a controls editor and a gamepad tester. Everything works with a keyboard, a mouse or a gamepad.

Controls

There are eight commands. Click the page first so it gets the keyboard.

  • Arrows or d-pad: move
  • Space / A: green, select
  • Esc / B: red, back
  • Enter / Start: blue, the file menu
  • Tab / Select: yellow, a tool-specific command

The mouse works everywhere. The CONTROLS tool shows the bindings and lets you change them for this session.

Your files

SAVE keeps a copy in this browser's storage and downloads it. LOAD brings back the stored copy; Open file... loads one from disk. Browser storage can be cleared, so keep the downloads. Storage on playdeezgames.github.io is shared with other pages on that site, so keep nothing private in it.

Key rebinding on this page lasts only for the session.
